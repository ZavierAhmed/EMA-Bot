# E11.5 Demo execution validation plan

This milestone supplies an execution foundation only. It does not place an order, migrate a database, or wire strategy/Paper signals to a broker.

When a separately authorized Demo test is scheduled, verify disabled-by-default behavior first, then readiness refusal for Real/Contest mode, missing server/fingerprint, disabled account trading, and disabled EA trading. Verify `OrderCheck` rejection leaves an auditable `Rejected` intent. For an accepted controlled order, record the exact ticket/deal, reconcile it after a simulated timeout, and close it by its exact ticket. Confirm duplicate client execution IDs never create another broker request.

MQL5 compilation remains a manual MT5/MetaEditor step in the target terminal environment; static source review is included in this repository validation.
